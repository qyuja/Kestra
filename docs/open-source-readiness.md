# 开源准备

本项目产品名为 Kestra，尚未发布仓库。本轮不迁移本地数据、不改 bundle ID、不上传文件。

## 发布前必须确认

- 由维护者选择项目源代码许可证并添加根 LICENSE；RunnerGallery 的 Apache-2.0 许可证仅覆盖相应第三方资源，不代表整个项目已获授权或已选择许可证。
- 核对所有第三方图片的再分发授权。当前客户端 PNG 来源包括 Icons8，不能直接假定可以随开源项目再分发；未确认的资源需替换或取得相应授权。
- 审核将要提交的文件及 Git 历史，排除账号令牌、邮箱、会话内容、日志、个人路径及机器配置。忽略规则不能清除已提交的历史。
- 不提交 `.build/`、`dist/`、`.codex/`、环境密钥文件和运行数据。当前账号缓存与任务数据位于用户 Application Support，不应复制进仓库。
- 执行 `swift test`、适配器脚本测试和应用构建；真实多账号登录/切换与各客户端兼容性需单独验收，不能用单元测试代替。

## 图标贡献

资源插件放在仓库 `icon-plugins/`，协议与本地安装方法见其 README。每个贡献应注明作者、来源和许可证，不包含可执行代码。应用不会自动从网络下载插件。

## 当前检查边界

已补充本机配置与日志的忽略规则，并移除 README 中的个人绝对路径。此检查不是完整密钥扫描、法律审查或发布安全审计。
